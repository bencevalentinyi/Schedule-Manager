Taxi Requests

Checks each taxi request from the Slack workflow against your rules (a live formula in the checks tab, read back by the workflow), shows the taxis of a day, and builds an email text. No Slack app; the only trigger is the optional one that keeps the email text up to date.

Layout

Any column of the requests tab in braces, e.g. {Address} {Phone Number} {Pet friendly}, and {date} (the taxi day), {taxi date} (the date the taxi drives: after midnight that is the next day), {next day}, {count} {n} (number of the taxi) {time} (arrival time). Saved with Save and apply.

Keep up to date for Slack

Writes today's email text (the taxis of the coming night) into one row of a tab, again and again inside the time window, so a scheduled Slack workflow can read it and send it, e.g. at 22:00. Uses the layout above and "Which requests".

Once, in the Apps Script editor: Triggers (clock icon) → Add trigger → function taxiEmailTick, event source Time-driven, Minutes timer, Every 10 minutes. Outside the window it does nothing. Save and apply fills the tab at once. The Slack steps are under Slack steps.

  1. Add a row to a spreadsheet → the requests tab, with Time when workflow started in the request ID column.
  2. Google Sheets → Select a spreadsheet row: this spreadsheet, tab Taxi Checks, column Date ID = Time when workflow started. Without an ID column: Name = the requester.
  3. Send a message to the channel with the request details and the selected row's Message, and the Prebooked / Deny buttons. (A message with buttons waits for the click, so the check must be in this message or before it.)
  4. In each button's branch: Update a spreadsheet row in the requests tab where Date ID = Time when workflow started (fill the decision column), and a message to the person.

Change the settings at any time: Save and apply rewrites the formulas, and the workflow keeps working. Save again after adding a team or moving staff columns.

Sending the email text at a set time

  1. Switch on Email text → Keep up to date for Slack, save, and add the taxiEmailTick trigger (see there).
  2. A new workflow that starts On a schedule: every day at the time to send (e.g. 22:00, inside the window).
  3. Google Sheets → Select a spreadsheet row: this spreadsheet, tab Taxi Email, column Key = tonight.
  4. Send the selected row's Text: Send a message to a channel or person, or an email step if your Slack has one. Count is the number of taxis and Updated when the text was last written.
