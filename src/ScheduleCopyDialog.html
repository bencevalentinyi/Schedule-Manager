Copy Schedules to Another Sheet

After each Quinyx import, the imported days are written into another spreadsheet's weekly blocks ("Week N", the dates, one row per person), in the old colors. New week blocks get the team's staff from this spreadsheet.

Where

You (and whoever imports) need edit access to it. It needs no script.

Which team

Only rows of these teams' people are written; other rows of the tab stay as they are.

Cells

Shift Shift lead Aircall Day Off Vacation Sick Paid leave

E.g. A for "SSC - CS - NOR A". Empty = not used.

Comma separated: a cell with one of these words is not changed to Day Off.

New week blocks

Like the old "Create a new weekly block": two empty rows, Week N, Support Associate and the dates, then the team's staff from this spreadsheet A–Z, two empty rows and the shift leads.

Before the name, e.g. "Shift Lead - ".

Every Sunday: once, in the Apps Script editor: Triggers (clock icon) → Add trigger → function scheduleCopyWeeklyTick, event source Time-driven, Week timer, Every Sunday, 6am to 7am. It adds next week's block; an import also adds any week it needs.
