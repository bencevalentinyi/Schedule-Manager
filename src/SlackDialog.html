    Run it automatically every day
    1. Save the columns here.
    2. Open Extensions → Apps Script → Triggers (clock icon) → Add Trigger.
    3. Function: generateSlackWorkflowMessage · Event source: Time-driven · Day timer · pick the hour (for example 6–7 am). Add a second trigger in the evening if a column shows tomorrow.
    4. In Slack Workflow Builder, schedule the workflow after that hour and read the row from the output sheet.

    Schedule Manager never creates triggers itself. Runs use the saved columns and today's date; errors appear in Apps Script → Executions.
