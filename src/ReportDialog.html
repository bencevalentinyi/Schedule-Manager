Schedule Manager imports Quinyx schedule exports into Google Sheets, stores every shift once in _SCHEDULE_DATA, and renders a daily view and a staff directory per team.

Typical workflow

  1. Setup & Configuration → Setup / Configure Spreadsheet — creates the internal sheets (run once; safe to repeat).
  2. Create New Team — the wizard creates "Team - Daily" and "Team - Staff" sheets.
  3. Fill the staff sheet (or use Schedule Management → View Staff Directory). Employee ID is the matching key.
  4. Schedule Import → Import Quinyx Export — upload the "Daily Schedule" export (or another CSV/XLSX), confirm the schedule date and layout, choose the shift types, review the preview, apply.
  5. On a daily sheet, change the date in cell B3 or the filters in row 3; the view refreshes automatically.

Key rules

  • Nothing is written until you confirm the preview. Every import can be undone (Undo Last Import, repeatable newest-first).
  • Duplicates are detected with the Quinyx shift ID if mapped, otherwise with team + employee + start + end + activity.
  • "Replace" only affects the imported team(s) inside the imported date range, and marks shifts REMOVED instead of deleting them.
  • Employees are matched by Employee ID (or an identifier field a team explicitly chooses). Without an ID, only a unique exact name match is used, and it is flagged.
  • Only the shift types selected for a team are imported. A team without a selection must choose one before its first import.
  • Operating hours (standard, 24/7 or custom across midnight) control which shifts the daily view includes and the headcount range.
  • Daily sheets are views: edits there are overwritten on refresh. Change data by importing.
  • Internal "_" sheets are protected with a warning only. Hiding or protecting sheets is not security.

Troubleshooting

  • Something missing or renamed: Maintenance → Rebuild Missing Sheets, then Validate Spreadsheet Structure.
  • Formatting broken: Maintenance → Repair Formatting.
  • Ambiguous dates (03/04/2026): choose DMY or MDY in the import mapping step and save the profile.
  • XLSX upload error: enable the Drive advanced service (Apps Script editor → Services → Drive API), or export CSV.
  • Technical errors are logged in the Apps Script editor under Executions.
