Monitoring Links

Monitoring links, daily list plans and agent lists, written to the "Monitoring Links" sheet for a Slack Workflow (see Sheet layout). Settings are stored in this spreadsheet only.

Sheet layout

Row 1 holds the column names, row 2 the values: A the key, B the date, then one column per item in the order of the list (its name in row 1, its link or plan text in row 2). A Slack Workflow selects the row where the key column equals the key value.

e.g. yyyy-MM-dd, yyyy. MM. dd, dd/MM/yyyy, EEEE d MMMM.

One row per item: row 1 holds the column names (Name, Kind, Date, Updated, Count, Missing, Text, URL, …); a Slack Workflow selects the row by Name.
